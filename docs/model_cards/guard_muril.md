# MuRIL advice guard

- **Base model:** `google/muril-base-cased` (Apache 2.0), fine-tuned as a binary classifier
- **Owner:** Akshat · **Notebook:** `notebooks/03_muril_guard.ipynb` (generated by `scripts/make_muril_notebook.py`, Kaggle)
- **Version:** the run recorded in `eval_results/guard_clf.json` and `guard_compare.json`

## Intended use

Says how likely a chat question is to ask for advice, a forecast or private data, in English, Hindi or Hinglish, so the chat can decline it and show the key facts instead (E8). It is an experiment against the keyword guard; the app uses the keyword guard unless `guard.backend: muril` is set.

**Out of scope:** judging whether an answer is correct, moderating other content, any use outside the FinSight chat.

## Training data

The advice-guard set in `data/gold/advice_guard_set.csv` (see [gold sets](../datasheets/gold_sets.md)): questions drafted with AI help, labelled advice or fact, split by language and label. The held-out test part was not reviewed by Akshat.

## Limitations and known failure cases

- It blocks too many fact questions on the held-out test, especially in Hinglish, where the keyword guard blocks none. That is why the keyword guard stays the default.
- The keyword rules were tuned on the whole set, so their test number is in-sample; MuRIL never saw the test questions.
- With 18 test questions, the intervals are very wide.

## Ethical considerations

A guard that blocks too little lets the chat drift into advice; one that blocks too much hides facts from the people who most need them. Both rates are reported, per language, so neither failure is hidden.

## How to use and reproduce

Set `guard.backend: muril` (or `FINSIGHT_GUARD__BACKEND=muril`) with weights in `models/guard_clf/` (never committed). Reproduce: `uv run python -m finsight.guard.clf_data` (split and package), then `uv run python -m finsight.guard.kaggle_clf push|status|fetch full` (Kaggle; `fetch` writes `eval_results/guard_clf.json`), then `uv run python -m finsight.evaluate.guard_eval` for `guard_compare.json`.
