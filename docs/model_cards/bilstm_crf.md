# BiLSTM-CRF tagger

- **Architecture:** word and character embeddings, a bidirectional LSTM and a CRF layer, trained from scratch (no pretrained weights)
- **Owner:** Akshat · **Notebook:** `notebooks/02_bilstm_crf.ipynb` (generated by `scripts/make_bilstm_notebook.py`, Kaggle)
- **Version:** the run recorded in `eval_results/bilstm_metrics-*.json` and `ladder_table.json` (gold v1)

## Intended use

A small, explainable baseline for the extractor ladder (E11): it tags each word of a passage as the start, inside or outside of an offer fact, for the same eight fields as the [QA extractor](extractor_qa.md). It shows how far a classic sequence tagger gets on this task. It is not the main extractor in the app.

**Out of scope:** investment advice, predictions, documents other than Indian IPO offer documents.

## Training data

The [weak labels](../datasheets/weak_labels.md) converted to BIO tags (`finsight.weaklabel.bio`). Showcase and gold IPOs are excluded.

## Limitations and known failure cases

- No pretrained language knowledge: unfamiliar wording around a value is often missed.
- Long names and lists of managers get cut, because the tagger has to find every word of the span.

## How to use and reproduce

`finsight.extract` loads the weights from `models/bilstm_crf/seed-<n>` (fetched with `python -m finsight.weaklabel.kaggle fetch bilstm-<seed>`; never committed). Reproduce with `notebooks/02_bilstm_crf.ipynb` on Kaggle, then `uv run python -m finsight.evaluate.run_gold` and `uv run python -m finsight.evaluate.ladder`.
