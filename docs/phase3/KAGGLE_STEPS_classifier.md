# KAGGLE_STEPS_classifier (C2.4)

**Job:** DeBERTa-v3-base, per seed two models: risk **category** (10 classes) and **seriousness band** (1, 2, 3, 4 = severe; levels 4 and 5 merged) · **GPU:** Kaggle T4 (free weekly quota, 0 Colab units) · **Expected:** smoke ~10 min; each seed ~1 h (both tasks) · **Notebook:** `notebooks/b2_classifier_base_kaggle.ipynb` (generated by `scripts/make_classifier_notebooks.py`)

**Data** (private Kaggle dataset `finsight-risk-classifier`, folder `data/processed/kaggle/risk-classifier/`):
`train.jsonl` 9,832 · `dev.jsonl` 1,060 (teacher labels after the C2.3b clean-up and remap-v2, split by company) · `test.jsonl` 150 (gold-150: human-verified category; band = the teacher's, there is no human seriousness label) · `labels.json`.

**Selection:** the best epoch per task and the best seed are chosen on **dev** only. Gold-150 is scored once, at the epoch dev chose (C-ADR-02). remap-v2 was tuned after the gold-150 review, so gold-150 scores are test-informed (C-ADR-15).

## Before (laptop, once the student job no longer uses the main folder)
1. Merge PR #218 (C2.3b) and the C2.3c PR, then in the main folder: `git checkout main && git pull`.
2. The split is already written (remap-v2). To rebuild it from scratch:
   `uv run python -m finsight.risks.teacher_cleanup run` then
   `uv run python -m finsight.risks.classify split --gold data/gold/gold150.jsonl` then
   `uv run python scripts/classifier_kaggle.py manifests` (the manifests must match the committed ones; `git status data/manifests` stays clean).
3. TF-IDF baseline (CPU, ~1 min, the E16 gate):
   `uv run python -m finsight.risks.classify baseline --gold data/gold/gold150.jsonl`
4. Upload a new dataset version: `uv run python scripts/classifier_kaggle.py dataset --username <you>`
   (creates it the first time, versions it after; wait until the Kaggle dataset page shows the new version with `test.jsonl`).

## Run (Kaggle CLI, from the laptop)
1. Smoke (200 / 100 / 50 rows, 1 epoch, seed 13, both tasks):
   `uv run python scripts/classifier_kaggle.py push smoke --username <you>`
   `uv run python scripts/classifier_kaggle.py status smoke --username <you>` until `complete`
   `uv run python scripts/classifier_kaggle.py fetch smoke --username <you>`
   Check: `models/risk_classifier/metrics-13.json` and `metrics-band-13.json` exist with `"smoke": true`; then delete those two smoke files (the summary ignores smoke runs, but the real seed 13 overwrites them anyway).
2. Seeds (one after the other, or two at once if your Kaggle account allows two GPU sessions):
   `uv run python scripts/classifier_kaggle.py push 13 --username <you>`
   `uv run python scripts/classifier_kaggle.py push 42 --username <you>`
   `uv run python scripts/classifier_kaggle.py push 2026 --username <you>`
   `status <seed>` until `complete`, then `fetch <seed>` for each.
3. Summary (E16): `uv run python scripts/classifier_kaggle.py summary` → `eval_results/b/classifier_base.json` with
   - `category`: dev macro-F1 per seed, mean ± sd, best seed, gate vs TF-IDF, **gold-150 macro-F1** of the best seed;
   - `seriousness`: dev macro-F1, **MAE**, **within-1**, **severe recall / precision** per seed and mean, and the best seed's scores on gold-150 (teacher bands; only 4 severe rows, so severe recall on gold-150 is indicative only).
4. Tell Claude: "C2.4 seeds are back" → ONNX export of the best seed (`scripts/export_onnx_classifier.py`), model card, C2.4 tick.

## If it goes wrong
- `status` shows `error`: `fetch <run>` still downloads the log; send Claude the last 30 lines.
- Out of memory on the T4: lower `BATCH_SIZE` to 8 and set `GRAD_ACCUM = 2` in `scripts/make_classifier_notebooks.py`, regenerate, push again.
- A rerun after a crash skips any task/seed whose metrics file is in an attached earlier output (resume).
