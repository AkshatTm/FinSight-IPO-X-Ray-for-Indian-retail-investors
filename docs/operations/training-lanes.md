# Training lanes and compute

The laptop never trains a model (it has a 4 GB RTX 2050). Training and large generation jobs ran on
free or prepaid GPU notebooks, in two lanes (C-ADR-04).

| Lane | Used for | Started by | How files move |
| --- | --- | --- | --- |
| **Kaggle** (T4 GPUs, weekly free quota) | field extractor, BiLSTM-CRF, MuRIL guard, risk classifier (base) | a local session, with the official `kaggle` CLI | private Kaggle datasets up, kernel outputs down |
| **Colab** (G4, L4, A100; prepaid units) | teacher bake-off and full teacher run, the student (4B and 8B), classifier large, gold-set pre-fill | Akshat, from `docs/phase3/COLAB_STEPS_<job>.md` | the Hugging Face dataset `AkshatTm/finsight-gpu-jobs` (C-ADR-13) |

## Kaggle

```bash
uv run python -m finsight.weaklabel.kaggle push|status|fetch <run>      # extractor, BiLSTM-CRF
uv run python scripts/classifier_kaggle.py manifests|dataset|push|status|fetch|summary [run]
uv run python -m finsight.guard.kaggle_clf push|status|fetch smoke|full  # MuRIL guard
```

The Kaggle token lives in `~/.kaggle/kaggle.json` and is never committed or printed. Notebooks are
generated by `scripts/make_*_notebook.py`, run a short smoke version first, and save the best epoch of
each seed. Seeds are 13, 42 and 2026.

## Colab

```bash
uv run python scripts/gpu_jobs.py push <job>          # inputs, _common.py and the notebook up to the HF repo
# Akshat opens notebooks/colab/<job>.ipynb in Colab and runs it (steps: docs/phase3/COLAB_STEPS_<job>.md)
uv run python scripts/gpu_jobs.py status <job> --wait # progress from the latest checkpoint
uv run python scripts/gpu_jobs.py pull <job>          # outputs to the paths the steps expect, plus the compute log
```

Notebooks checkpoint to the job repo after every batch and resume from it after a disconnect. Weights
leave Colab as adapters, GGUF or ONNX, never merged fp16. `HF_TOKEN` comes from the environment or
`.env` and is never printed.

!!! warning "Repository visibility"
    `scripts/gpu_jobs.py` describes `AkshatTm/finsight-gpu-jobs` as a private dataset, but on 7 Nov 2026
    an unauthenticated `hf download --dry-run` of the student GGUF succeeded, so the repo appears to be
    public. Check its visibility on Hugging Face: the student is trained on data derived from the
    CC BY-NC-SA 4.0 corpus ([NOTICE](https://github.com/AkshatTm/FinSight-IPO-X-Ray-for-Indian-retail-investors/blob/main/NOTICE)).

## Compute log

`scripts/log_compute.py` appends each Colab or Kaggle `run_summary.json` to
`eval_results/c/compute_log.jsonl` (`gpu_jobs.py pull` does it automatically). It holds 9 rows: five
rate checks of the Colab GPU classes and these jobs (Colab units used):

| Job | GPU | Units |
| --- | --- | --- |
| Teacher bake-off | G4 | 4.03 |
| Student 4B (C2.5) | G4 | 11.5 |
| Student 8B | G4 | 16.4 |
| Classifier large | G4 | 7.7 |

The full teacher run (12,000 risks in 44.7 min on the G4) and the Kaggle runs are recorded in their own
run summaries (`eval_results/c/teacher_full_run_summary.json`, the model cards), not in this log.
Phase 4 used 0.12 Colab units (`docs/phase4/PROGRESS_ARGON.md`) before it was closed.
