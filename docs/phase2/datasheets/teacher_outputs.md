# Datasheet — teacher outputs (M5, B2.3)

Status: **code ready (B2.3a); no outputs yet.** The numbers below are filled from `filter_report.json` and `eval_results/teacher_quality.json` by the B2.3b session, never typed by hand.

## Motivation
Labels (category, seriousness, hard fact) and plain-English rewrites for about 5,000 corpus risk factors, to train the risk classifier (M3/M4, B2.4) and the simplifier student (M6, B2.5). One-time, offline. The teacher is never served.

## Composition
| File (gitignored, `data/processed/teacher/`) | One row per | Fields |
|---|---|---|
| `risks.jsonl` (input, from B2.1b) | corpus risk | `risk_id`, `company`, `title`, `body` |
| `raw.jsonl` (Kaggle output) | risk sent | `risk_id`, `raw` (the teacher's text), `model`, `prompt_version` |
| `labels.jsonl` | kept risk | `risk_id`, `company`, `category`, `seriousness_1to5`, `hard_fact`, `label_source` |
| `simplify.jsonl` | kept risk | `risk_id`, `company`, `original`, `simple`, `label_source` |
| `filter_report.json` | run | total, kept, drops and drop rate per reason |
| `quality_sheet.csv` | 100 sampled kept risks | outputs + blank `faithful`, `category_correct`, `notes` |

Categories (10): financial, debt_liquidity, customers_suppliers, competition, legal_litigation, regulatory, promoters_governance, operations, technology_data, market_macro (`core.schemas.RiskCategory`).

## Collection process
- **Source text:** risk factors segmented from public offer documents in the 2018–2023 corpus (B2.1b).
- **Model:** `Qwen/Qwen3-14B-AWQ` (Apache-2.0), with thinking off. Fallback: `Qwen/Qwen2.5-14B-Instruct-AWQ`.
- **Inference:** vLLM 0.8.5 on a Kaggle T4, fp16 compute, with guided JSON (`risks.teacher.OUTPUT_SCHEMA`) at temperature 0.2. Prompt `teacher-v1` (`risks.teacher.SYSTEM`).
- **Notebook:** `notebooks/b2_teacher_kaggle.ipynb`, generated by `scripts/make_teacher_notebook.py`.
- **Order:** smoke (50) → pilot (500) → quality go/no-go → full run.
- **Checkpoints:** every 100 risks; a rerun resumes.

## Preprocessing (filters, `risks.filters`, B03 §3.3)
The first failing check names the drop: invalid JSON → category not in the list → schema → a number in `simple` that is not in the original → a forbidden phrase (`configs/forbidden_phrases.yaml`) → more than 70 words → certainty changed (hedge dropped, definite word added, or hedge added to a fact) → duplicate of an earlier rewrite. The student's rewrites face the same number, phrase, length and certainty checks (B2.5).

## Uses
- **Use it for:** training and evaluating M3/M4 (labels) and M6 (rewrites).
- **Never:** as ground truth for evaluation. Gold-150 and the 50 gold risks are verified by Akshat.
- **Never:** shown to users as FinSight's own words without the student's post-checks.

## Labels are AI-made (disclosure)
- Every row carries `label_source = teacher:<model>:<prompt_version>`.
- Quality is measured on 100 sampled outputs, pre-filled by Claude chat where Akshat asks and verified by Akshat, with the number of values he changed recorded.
- The quality sheet is single-annotator. Report it as "agreement with Akshat-verified ratings".

## Distribution and maintenance
- Not redistributed. Outputs stay in gitignored `data/processed/teacher/` and in a private Kaggle dataset.
- Only aggregate numbers are committed (`eval_results/teacher_quality.json`).
- Source documents are public SEBI filings.
- A new prompt version means a new `prompt_version` and a full re-run of the filters.
